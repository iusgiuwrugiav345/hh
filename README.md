# Drivee Passenger VIP Demo (Expo Go + React Native)

Демо-приложение в стиле Drivee: 
- мини-игра Flappy Bird (нужно пройти 20 труб);
- после этого разблокируется карточка в инвентарь пассажира;
- из карточки выпадают украшения профиля;
- копится опыт (XP) и растёт уровень;
- каждые 10 уровней даётся VIP на 3 дня;
- для водителя VIP-заявки выделяются, и за такую поездку можно выдать авто-оценку 5★ от Drivee.

## 1) Что нужно скачать

### На компьютер
1. **Node.js LTS** (рекомендуется 20.x):
   - скачать с официального сайта: https://nodejs.org/
2. **Git** (если ещё не установлен):
   - скачать: https://git-scm.com/downloads
3. **Visual Studio Code** (или любой редактор):
   - скачать: https://code.visualstudio.com/

### На телефон
1. **Expo Go**:
   - Android (Google Play)
   - iOS (App Store)

## 2) Куда вставлять код

### Вариант A: если у тебя уже есть папка проекта
1. Открой папку проекта в VS Code.
2. Замени/создай файлы:
   - `App.js`
   - `package.json`
   - `app.json`
   - `babel.config.js`
3. Вставь код из этого репозитория в соответствующие файлы.

### Вариант B: создать новый проект с нуля
1. Открой терминал.
2. Выполни:
   ```bash
   npx create-expo-app drivee-passenger-vip-demo
   cd drivee-passenger-vip-demo
   ```
3. Замени содержимое файлов на код из этого репозитория.

## 3) Установка зависимостей

В терминале в папке проекта:

```bash
npm install
```

## 4) Запуск в Expo Go

```bash
npm run start
```

Дальше:
1. Откроется Expo Dev Tools в браузере и QR-код в терминале.
2. Открой Expo Go на телефоне.
3. Отсканируй QR-код.
4. Приложение запустится на устройстве.

## 5) Как работает логика

### Пассажир
- Тапом по игровой зоне управляешь «птичкой».
- Когда лучший результат достигает **20 труб**, кнопка открытия карточки становится активной.
- Каждое открытие карточки:
  - добавляет случайное украшение в инвентарь;
  - даёт +120 XP.
- Уровень повышается автоматически по накопленному XP.
- На каждом уровне, кратном 10 (10, 20, 30...), выдаётся VIP на 3 дня.

### Водитель
- В списке заказов VIP-пассажиры выделены.
- Для VIP-заказов отображается сообщение о бонусе:
  - авто-оценка **5★ от Drivee**;
  - клиент дополнительно может оставить отзыв вручную.
