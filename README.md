# DPI Desync Demo App

Небольшое desktop-приложение на Tkinter, в котором значение DPI в меню настроек **умышленно не совпадает** с фактическим DPI, применяемым к интерфейсу предпросмотра.

## Что делает приложение

- В меню есть ползунок **Displayed DPI** — значение, которое видит пользователь.
- Реальный масштаб (фактический DPI) рассчитывается как `Displayed DPI + Desync offset`.
- Ползунок **Desync offset** позволяет менять рассинхронизацию.
- Кнопка **Randomize desync** быстро генерирует другое смещение.

## Запуск

```bash
python3 app.py
```

## Требования

- Python 3.8+
- Tkinter (обычно уже встроен в стандартную поставку Python)
